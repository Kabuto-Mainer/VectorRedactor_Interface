# Описание

Для создания уникальных `ID`, которые требуются практически в каждом месте проекта планируется использовать сочетание заданного префикса + рандомизированная часть, зависящая от времени, IP, машины и т.д.

# Типы ID и префиксов

Существует 2 типа ID: внешние и внутренние.
Внешние ID - это идентификатор интерфейса.
Внутренний - в свою очередь идентификатор объекта внутри интерфейса или внутри другого модуля.

Между собой внешние и внутренние ID никак не связаны и необходимо решить вопрос возможной коллизии только внутри отдельного ID.
Для этого вводится префикс - часть ID, задающаяся системой или пользователем.
Основное предназначение - что бы пользовательские ID никоем образом не перекрыли системные ID + при малом количестве разработчиков это полностью решает вопрос коллизии.

И у внешнего, и у внутреннего ID будут одни и те же префиксы.
